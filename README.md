# MultiBank — Fake Online Banking System

A web-based fake banking platform where users can create realistic online banking accounts from 30+ real bank templates across 8 countries, with a full admin panel for fund management.

## Features

- **40+ Bank Templates** across 8 countries (Germany, Australia, USA, France, Italy, UK, Canada, Japan)
- **Each bank** has authentic branding, colors, logos, and realistic interface
- **Full dashboard** per account — balance, transactions, transfers, cards, statements
- **Admin panel** — manage all accounts, add/remove funds, export data
- **Per-bank themed** login pages
- **Mobile responsive**

## Tech Stack

- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Backend/Database**: Supabase (PostgreSQL, Auth, Storage)
- **Deployment**: Vercel + Cloudflare
